# TextToCAD · Argon R1

Публичная версия продукта **TextToCAD** и флагманский демонстрационный проект для сообщества:

## Argon R1 — Open Source Tesla Roadster 2026

Этот репозиторий предназначен для согласованных публичных выпусков TextToCAD, материалов и исходного кода демонстрационного проекта Argon R1.

### Статус

Репозиторий создан. Подготовка первого публичного выпуска продолжается.

### Публикация

Разработка и резервное копирование ведутся в приватном контуре. После разработки и согласования в этот репозиторий добавляются материалы, предназначенные для сообщества.

Описание установки, состав публичной версии, условия использования и инструкции по участию будут добавлены вместе с первым выпуском.
